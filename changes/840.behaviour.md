**A project's model, language, preview policy and removal are actions.** A front end of one's own changes them with `POST /api/act/{name}` — `project_set_model`, `project_set_language`, `project_set_preview` and `project_remove` — and `openfactory project set-model`, `set-language`, `set-preview` and `remove` map onto the same rows with their flags, exit codes and success output unchanged; like every row that changes the installation, they are refused to a credential scoped to the board or the product.
- A model value is saved verbatim as before, with one exception: a value that begins with `-` is refused with a sentence where a project's model is set through the registry — `project set-model`, `project add --model` and the registry file. Every harness is handed the model as a single `--model=<value>` token; that one-token form is what holds a value from `OPENFACTORY_<ROLE>_MODEL`, which is read directly and not through the registry.
