**A card names its context repository without a path of the operator's machine.** On the local row, every card the product role filed from a requirement linked the context repository to its directory on the machine, `~/.openfactory/context/<name>`, which nobody reading the board can open and which wrote the operator's home directory, account name included, into every card. A card now links the context repository only by an `http://` or `https://` address, as it does on a hosted forge, and otherwise names it as plain text.
