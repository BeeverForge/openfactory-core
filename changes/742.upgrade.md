**Nothing changes for an installation that declares no credential store**: with `OPENFACTORY_CREDENTIAL_STORE` unset every credential is read from its variable, byte for byte, as before. The worker, the panel and a remote box no longer copy a GitHub App key handed over as content into a temporary file at start-up, and no longer set `OPENFACTORY_GH_APP_KEY` to point at it; the key is read as content, as it already was.
