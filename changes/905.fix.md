**`openfactory bot-token --key-path <file>` signs with the key in that file.** The option was accepted and ignored: the key always came from `OPENFACTORY_GH_APP_KEY_CONTENT` or `OPENFACTORY_GH_APP_KEY`, so a new `.pem` could not be proven before it was deployed. An explicit path now wins over both, a path that cannot be read is refused by name, and without the option the key is found as before.
