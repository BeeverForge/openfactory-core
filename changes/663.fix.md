**Every project of a product of several projects is linked to its context repository.** Several registry projects that point at one context repository are one product, but the product link compared the context's `product:` with each project's name, so only one project could ever pass: `doctor` failed `product_link` on the others, the product role could not read the product's requirements from them, and an impediment card was filed on each of their boards. A project is now linked when the context lists its code repository in `sources:`, written the same way, whatever the product is called. A project the context does not list is still refused, and the product's name alone admits a project only when it is the project's own name.
