**A remote box's launcher can declare that it resolves credential references itself, and it is then handed the reference to a stored secret, never the secret.** A launcher declares it with `resolves_references = True` and a `launch` that takes the `references` keyword; one that declares without taking it is refused by name when the box is first asked for. A launcher that declares nothing is handed only short-lived minted tokens, and a credential held in the credential store is refused for it, before anything is launched, in a sentence that names the box and the declaration it lacks. `openfactory doctor` has a `launcher_credentials` line saying, for each remote box, whether its launcher receives references or values, or that its runner is not installed here; it fails when this deployment's box has a launcher that declares nothing and a project's forge or tracker secret is held in the credential store, naming the reference, never the value.
