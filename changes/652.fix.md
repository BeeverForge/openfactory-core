**The installer shows one command to start the factory, and it works.** `openfactory init`, run by the installer, also printed `docker compose --env-file /out/.env.compose up -d --build`, naming a path that exists only inside the installer's container and a build an installation from published images cannot do. The installer's own command is now the only one. Run by hand, `init` names the environment file as you passed it, from the directory you are in, and adds `--build` only in a checkout that builds its own images.
