**A working tree under a directory the factory cannot search is no longer reported as gone on Python 3.14.** When a card's branch is checked out in a tree inside a directory the factory has no permission to enter, the factory could not tell whether the tree was still there. On Python 3.12 it held the job and named the tree. From Python 3.14 it called the tree gone and told the person to remove it. It now holds the job on every Python version and treats a tree as gone only when it could look and found nothing there.
