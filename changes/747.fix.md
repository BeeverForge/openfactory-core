**A job on the worktree box keeps its repository while the cache refreshes.** When the repository cache found its checkout behind the base or dirty, it swapped the checkout out, and a job whose worktree had been added to it lost its git directory mid-run: every git command failed with "not a git repository" and the finished work was never pushed. The checkout now stays in place while a job's worktree is on disk, for at most a day, and the log says which worktree is holding it.
