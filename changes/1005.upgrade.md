**A core file that uses YAML anchors or aliases must be written without them.** A `.openfactory/` manifest, a `product.yaml`, a card's or a document's front matter, a profile or the project registry that defines `&name` and reuses it with `*name` or `<<: *name` is now refused with a sentence naming the anchor and its line; write the repeated value out in each place it is used. Compose files, CI pipelines, Kubernetes manifests and OpenAPI documents keep their anchors.
