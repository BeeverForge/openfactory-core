**A paused Codex job resumes.** In its default sandbox mode the Codex harness resumed a paused job with a sandbox flag that `codex exec resume` refuses, so the job failed at once with exit code 2 instead of continuing; a resumed session is now handed its sandbox, `workspace-write`, as a configuration override that the command accepts. Jobs run with `OPENFACTORY_CODEX_FULL_ACCESS` were not affected and are unchanged.
