**A card GitHub would accept is created whatever its script.** The GitHub tracker passed a new card's body as a command-line argument, which Linux refuses past 131,072 bytes, so a body within GitHub's 65,536 characters failed to create when it was written in an accented, Asian or emoji-rich script — and since a split card's children carry their parent's other sections, a split could fail partway; the body now goes to `gh` on standard input, as an edit's already did.
