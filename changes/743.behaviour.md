**`openfactory doctor` checks that a deployment serves one GitHub organisation.** A new `installation_scope` line asks the configured GitHub App which organisation it is installed on and fails, naming both organisations, the projects in each and the repair, when the registry names another one or spans more than one; with a registry in one organisation and no App configured, or an App beside a static token that every GitHub project uses instead, it says the check does not apply and asks the App nothing. The reason for the rule, and how to run one deployment per organisation, is in the configuration reference.
