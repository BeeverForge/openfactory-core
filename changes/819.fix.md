**A `product.yaml` key that is not a string is named instead of crashing the reader.** A key of `.openfactory/product.yaml` that YAML reads as something other than text, such as `1:`, `on:` or `yes:` (YAML reads both as true), `~:` or a date, written there or merged in with `<<`, made every reader of the file raise an error, so the product module and a product's preview failed instead of saying which file to fix; a list or a mapping written as a key was refused, but in the YAML parser's own words, naming no key. Each is now one sentence that names the key as written, its line, what YAML reads it as and the remedy, for example `.openfactory/product.yaml is invalid at 'on' (line 3): a key must be a string, not !!bool; quote the key if it is meant as text`.
