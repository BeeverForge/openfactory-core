**Every frame the API's four streams push has a published shape.** `docs/reference/events.schema.json`, beside `openapi.json`, is a JSON Schema that describes each frame as one envelope — its kind, an id, a time, the project, and the product where one applies — around the frame's own fields, typed per kind, so a front end of one's own no longer has to read the panel to learn them. The streams still send their frames as before; a stream that sends this envelope is to follow.
