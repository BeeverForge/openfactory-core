**A symbolic link that points to itself where a working tree of a repository used to be no longer stops that repository's jobs on the worktree box with a traceback.** On Python 3.12, the oldest Python the factory runs on, every job on the repository failed as it started with `Symlink loop from …`. A job whose branch that tree does not hold now starts, and a job whose branch it holds waits for you and names the tree, as for any tree the factory cannot look at, without calling it gone. A directory at the job's own path whose `.git` file names a path through such a link now stops the job with the factory's own sentence, which names the directory and the command that moves it aside, instead of `Symlink loop from …`.
