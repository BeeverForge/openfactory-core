**A clone of a repository on the same machine no longer fails while git repacks that repository in the background.** Every clone the platform runs now reads through git's transfer protocol rather than copying the repository's object files one by one. This affects the local forge's repositories, the worker's cache, and the box and preview workspaces cloned from it. With newer git (2.55 and later), those copies could fail with `hardlink different from source` or `failed to copy file`, because git's automatic maintenance repacks small repositories after a commit, push or fetch.
