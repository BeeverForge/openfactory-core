**On Jira, an email and an API token of two different accounts are named as such, instead of every card reading as missing.** Jira Cloud answers a request made with another account's token as if nobody had signed in, so every card that exists came back as not found, and polls and jobs parked on it. When a card is not found, the tracker now asks Jira who is signed in. When the answer is nobody, it refuses with a sentence that says the email and the token are not one account's and how to pair them, or that no token reached it. A card that is really missing still reads as missing, and so does any card where Jira could not answer the question.
