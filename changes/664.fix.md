**On the local row, a product of several projects reads each project's code where that project lives.** The local forge answered any repository name that was not its own project's as a context repository under `~/.openfactory/context/`, so another project of the same product was looked for where it does not exist: onboarding could not clone it, every conversation logged a failed sync, an impediment card said the product agent could not open the product's code, and the product role told the person it could not read that repository. A registered local project of the same product is now read at its own `repo_path`. A project of another product, or of none, is never read as a member, and a context repository is still the installation's own.
