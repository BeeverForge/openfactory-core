**The CLI image builds when docker/extra-ca/ holds a root certificate.** Since 0.1.0, its trust step looked for a Python module its base image does not carry, so building the CLI image from source behind TLS interception failed — the release's upgrade rehearsal, the build profile of the compose file, a deployment that builds its own images; it now adds the root to the system trust store the image already has and points pip at it, as the worker image does. The published images were built without an extra root and were never affected.
