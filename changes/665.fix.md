**A card of another repository of the product is never run in this project's repository.** On a board that keeps every card in one place, a breakdown's front meant for another repository of the product was filed on this project's board with nothing recording where it belonged, so queueing it ran its job in this project's repository: the agent changed nothing, no pull request was opened, and the park held the deployment's only job slot for hours. Such a card now records the repository it belongs to (`belongs_to:` in its front matter, and a sentence a person reads), and it is refused when queued, taken out of the queue if it reaches it another way, and parked at pre-flight if a job starts on it regardless, each time with a sentence naming the repository it belongs to.
