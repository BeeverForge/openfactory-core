**A requirement's own text can no longer write a heading into it.** A line break in a drafted requirement's title, *Why*, a criterion, an out-of-scope line, an affected path, an open question or a conflict could open a line such as `## Decisions taken during execution`, and the corpus read that one as the decision register: the requirement counted a decision nobody took, and the next decision was written into it. The title and every bullet are now written on one line, and a line of a section's text that would open a heading is written with `\#`, which Markdown shows as the `#` outside a code block.
