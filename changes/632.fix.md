**What the product owner writes in a project's documentation repository, and what it says about it, is in the project's language.** On a project that speaks English, a missing requirement used to be answered in Portuguese, and the documentation repository took commits and pull requests titled in Portuguese ("requisito 0002: abandonado por …", "Levantamento inicial: …"). Those writes and their answers now follow the project's language. So do the fact files, the note on a card held back because its automatic review did not answer, a decision row's conversation, a case's reading and the tech lead's note on a remedy that never worked. A reason given in English when closing a card ("close #511 because …") is now recorded on the card.
