**A job that continues a pull request waits for you when its branch is checked out somewhere else.** On a machine running the worktree box, an adjust, a repair or a resumed job failed with git's own sentence when the card's branch was out in another working tree, such as a tree you made to review the pull request, or your own checkout, and `resume` only reopened the gate. The job now holds, names the path that has the branch and the command that frees it (`git worktree remove <path>`, or switch that checkout to another branch), and `resume` checks again. Nothing the job did not create is removed, and the job no longer runs `git worktree prune` in your repository.
