**A Jira ticket written in Jira's own editor keeps its Heading 2 sections and its bullets.** A description with an Acceptance criteria heading and a bulleted or numbered list reached the factory as bare lines, so it found no sections and no criteria and refused the ticket as incomplete; a Heading 2 and list items now arrive as the sections and criteria they are (a heading of any other level does not open a section yet, so write those headings as Heading 2), and a description the factory wrote to Jira reads back with its blank lines, so a split card's last item no longer swallows the line under it.
