**The stack preflight and `openfactory doctor` send a missing agent credential to the credential store you declared.** When `.env.compose` sets `OPENFACTORY_CREDENTIAL_STORE` to a store other than `env`, `openfactory preflight` no longer says to put the token in `.env.compose`. It says the credential is expected in that store, that the preflight does not read the store, and that `openfactory doctor` checks it once the stack is up. The doctor's own remedy for the missing credential names the same store, and for `file` the directory `OPENFACTORY_CREDENTIAL_DIR` names, instead of `.env.compose`.
