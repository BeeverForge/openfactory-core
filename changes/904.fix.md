**The stack preflight sends a missing agent credential to the credential store you declared.** When `.env.compose` sets `OPENFACTORY_CREDENTIAL_STORE` to a store other than `env`, `openfactory preflight` no longer says to put the token in `.env.compose`. It says the credential is expected in that store, that the store cannot be checked before the stack runs, and that `openfactory doctor` checks it once the stack is up.
