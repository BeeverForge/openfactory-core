**A project on a vendor that names its own credential variable must now have that variable, or `token_env`, set.** That is Jira (`JIRA_API_TOKEN`) and any add-on vendor whose credential row declares `env=`. Such a project used to fall back to the deployment's pair (`OPENFACTORY_TRACKER_TOKEN` / `OPENFACTORY_FORGE_TOKEN`, then `OPENFACTORY_BOT_TOKEN`) when its own variable was unset, which `docs/operations.md` once suggested for a mixed deployment; it no longer does. Until the variable is set, a Jira project's cards read as "no API token reached this tracker", and `openfactory doctor` names the variable the row wants.
