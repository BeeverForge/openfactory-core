**A Claude Code run that dies before its result is parked as rate limited only when the CLI said so.** When a run was killed or stalled before the CLI printed its result, the whole transcript was searched for limit wording, tool output and the repository's own files included, so a repository about throttling (`429` handlers, quota code, a `rate-limiter` directory) parked its own runs as a usage-limit pause with a resume timer, and so did any such run whose stream carried the CLI's routine rate-limit status event. The pause is now read only from what the CLI itself said: what it printed outside the event stream, the error message it writes in the model's place, and a rate-limit event whose status is `rejected` (its reset time is shown). Codex, Kimi and OpenCode already read only their CLI's own words and are held to the same rule.
